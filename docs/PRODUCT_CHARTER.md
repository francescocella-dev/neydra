# NEYDRA — Product Charter v0.1

## Why it exists
An aesthetically compelling, actually useful, voice-led AI companion that people would want to install after seeing a truthful video demonstration.

## Product experience
- **Holo**: original, elegant, semi-realistic holographic 3D visage, luminous wire/particle materials and meaningful facial articulation.
- **Mini**: original premium small 3D robot, rounded body and expressive face display.
- Avatar switching preserves the conversation; both share one dialogue, speech, and state engine.
- Natural-feeling Italian voice dialogue with captions, optional typing, cancellation and interruption.
- Separate ChatGPT general conversation and Codex project-assistance modes, **only through legitimately authorized endpoints**.
- A public, Windows-first desktop build with understandable installation and permissions.

## Fixed conditions
- No cost beyond the user's existing **eligible** ChatGPT subscription. Users connect **their own** accounts. If plan authorization is unavailable, block the connected feature; never fall back to a separately billed API.
- Public GitHub repository and transparent documentation; no backend service to host.
- Two real 3D avatars from the first visual work; do not ship low-quality 2D stand-ins.
- Local speech processing; permissions, storage and model license compliance.
- User-approved workspace boundaries and dangerous operations; no general-purpose unrestricted computer control.

## Quality gate for first public release
- An account-specific official sign-in and a successfully completed model request with no separately billed API configuration.
- Working and appropriately permissioned Codex activity against a disposable test project.
- Real conversation, Italian STT/TTS, practical interruption, captions and error states, tested on Windows hardware.
- Both 3D characters visually approved, with repeatable idle/listening/processing/speaking/interrupted/error transitions, expressive head/eye actions and meaningful mouth sync.
- Build, tests, installer or portable package, asset license manifest, security review, accessible settings, honest README and unedited real demo.
- No public v1 until ALL applicable gates pass. Internal prototypes and CI artifacts are not releases.

## Deferred, but architecturally considered
Android, cross-device synchronization, cloud backend, continuous wake word, autonomous general OS control, full remote coding of an offline PC.

## Limitations to state clearly
- Plus plans have limits and are not an unlimited paid API.
- SIWC authorization, account eligibility, supported models and endpoint restrictions require live validation.
- Mobile SIWC and full ChatGPT product parity are NOT guaranteed.
- 3D concept images do not imply animatable 3D assets exist.
